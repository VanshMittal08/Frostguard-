❄️ FrostGuard – Smart Cold Chain Monitoring System

A frontend prototype for monitoring shipment temperatures and managing cold-chain operations.

🌐 Live Demo: https://vanshmittal08.github.io/Frostguard-/

📌 About the Project

FrostGuard is a web-based cold-chain monitoring dashboard designed to demonstrate how temperature-sensitive shipments can be monitored and managed. It provides an interactive interface for tracking temperature readings, managing shipments, and identifying potential temperature violations.

✨ Features

- Interactive Dashboard: View shipment statistics and temperature information.
- Temperature Monitoring: Track simulated temperature readings.
- Shipment Management: Add, search, and manage shipments.
- Smart Status Detection: Identify SAFE, WARNING, and CRITICAL temperature conditions.
- Alerts & Incidents: View and manage temperature-related incidents.
- Threshold Settings: Customize minimum and maximum temperature limits.
- Local Storage: Save prototype data in the browser.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

🚀 How to Run

1. Clone or download this repository.
2. Open the "index.html" file in your browser.
3. Explore the FrostGuard dashboard and its features.

⚠️ Project Status

This is a frontend prototype using sample data and simulated temperature readings. It does not currently connect to real IoT sensors or a backend server.
